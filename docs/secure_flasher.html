Gaggiuino ESP32-P4 Secure Flash

Prototype for ESP32-P4 boards with flash encryption enabled and Secure Download Mode active. Runs via Web Serial; does not erase the chip.

Important: Use only binaries already encrypted for this board's key and exact flash offsets. Never use ordinary plaintext application/web images on a release-locked board. This tool does not flash the bootloader, partition table or NVS. Test on a recoverable development board before public deployment.

Always flashes both application slots (0x10000 and 0x390000). Bootloader, partition table, otadata, NVS, tempdata and coredump remain untouched.

Reads manifest_lcd_p43.json or manifest_lcd_p47.json from this page's directory. The manifest's parts[].path points to the hosted binary files.

Ready. Enter the ESP32-P4 ROM download mode and connect via Chrome or Edge on HTTPS/localhost.

Based on esptool-js 0.7.0 plus the ROM's SPI_SET_PARAMS command. Secure Download Mode prevents reading back the flash for verification; success means the ROM acknowledged writing all blocks, not that boot was verified. You may need to reset the board manually afterwards.
