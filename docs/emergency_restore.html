UI Firmware Reset

This tool is undergoing testing and may not work in all browsers.

⚠️ Reset erases settings!
Backup PZ, load cell factors, custom profiles, etc. before starting.

Recovery Steps:

  • Connect the screen or headless module directly to a computer using a USB A-C data cable.
  • Select the LCD or Headless option that matches your hardware and then click Connect.
  • Grant browser permission (if necessary) and connect to the USB JTAG/serial debug unit.
    For the headless module:
    Hold BOOT, tap RESET, release BOOT before trying to connect to the USB JTAG/serial debug unit. If the unit connects but install fails, try again and continue holding BOOT until starting the install.
  • Follow recovery instructions with default settings (note that recovery may take longer than the estimate)
Post-Recovery Steps:
  • Connect the screen or headless module to a Wi-Fi network
  • Navigate to System Settings → About and select "Update All"
    If the Core build number is zeros then it can't be automatically updated - download and flash the latest core bin to your STM32 with an ST-Link/mini debugger.
